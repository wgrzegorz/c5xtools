First public release. A dependency-free TMS320C5x toolchain in portable C99 -
assembler, linker, hex/ROM converter and disassembler - whose output is
byte-compatible with the TI tools. It ships with an offline test suite, section 1
manual pages, and an attested multi-platform release pipeline. This 1.0.3 merges
and supersedes the internal 1.0.0-1.0.2 iterations.

## Tools

| Tool     | Role                                                                 |
|----------|----------------------------------------------------------------------|
| `c5xasm` | assembler: source to a TI COFF object (or a flat word listing)       |
| `c5xlnk` | linker: COFF objects to an absolute or relocatable image             |
| `c5xhex` | converter: COFF to Intel-HEX / Motorola-S / TI-tagged / ASCII / bin  |
| `c5xdis` | disassembler: image back to re-assemblable source (byte-exact)       |

## Running

Windows (cmd or PowerShell):

```
c5xasm.exe fir.asm -coff -o fir.obj
c5xlnk.exe fir.obj -o fir.out
c5xhex.exe fir.out -f intel -o fir.hex
```

DOS: run under a DPMI host, for example CWSDPMI.EXE in bare DOS, or a DPMI
environment such as DOSBox or a Windows 9x DOS box.

## Build from source

```
make            # build the four tools
make test       # run the offline test suite
make install    # into $(PREFIX)/bin and $(MANDIR)/man1
```

A C99 compiler (clang or gcc) and `make` are the only build requirements; a
make-free build is available through `scripts/build.sh` (Unix) and
`scripts/build.bat` (Windows). Cross-compiling for static Linux, Windows and
32-bit DOS is documented in `BUILDING.md`.

## Verifying the binaries

Every archive carries a signed build-provenance attestation produced by this
repository's release workflow on GitHub's runners:

```
gh attestation verify c5xtools-1.0.3-<target>.zip --repo wgrzegorz/c5xtools
```

## Highlights

- Output byte-compatible with the TI tools: the COFF objects/executables and the
  Intel-HEX / Motorola-S streams match the reference assembler, linker and hex
  utility; the disassembler re-assembles byte-exact.
- One shared COFF module behind the assembler writer, linker reader/writer and
  hex reader, so they cannot drift.
- Built on native GitHub runners per platform (Linux x86-64/arm64, macOS
  universal, Windows 64/32-bit via MSVC; 32-bit DOS cross-built with DJGPP), each
  archive attested.
- CI: conformance on Linux/macOS/FreeBSD, a functional round-trip and byte-exact
  cross-platform determinism over every example and hex format, disassembler
  fidelity, AddressSanitizer + UBSan, reproducible builds and a bug-class
  `-Werror` build.

Full history is in `CHANGELOG.md`.
